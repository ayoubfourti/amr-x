# Robot Description

URDF and SDF robot model definitions.

## Purpose

Define robot structure, dimensions, sensor placement, and physical properties in machine-readable format.

## Selected Stack

- URDF (Unified Robot Description Format)
- SDF (Simulation Description Format)
- ROS 2 URDF parser

## Future Content

- Base platform URDF
- Sensor placement definitions
- Link and joint definitions
- Physical properties and inertia
- Modular interface definitions
