# AMR-X

Autonomous modular mobile robot platform with remote monitoring, mission management, and modular add-ons adaptable to factories, warehouses, logistics, hospitals, hotels, universities, and security operations.

## MVP Direction

Simulation-first development with dashboard-first monitoring. Selected technical stack. Hardware and CAD decisions pending validation.

## Selected Technical Stack

### Robotics

- Ubuntu 24.04
- ROS 2 Jazzy
- Nav2
- Gazebo Harmonic
- SLAM Toolbox
