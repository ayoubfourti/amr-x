# Agent Rules

## Purpose

This file defines the rules for AI coding agents working on AMR-X.

## General Rules

- Follow user instructions exactly.
- Do not add unrequested features.
- Do not create implementation code unless explicitly requested.
- Do not choose new technologies unless explicitly requested.
- Do not invent market data, prices, sources, or technical specifications.
- Use `TBD` for undecided items.

## Repository Rules

- Every task must have a GitHub issue.
- No direct push to `main`.
- Work on a branch.
- Open a pull request.
- Keep pull requests small.
- Update documentation when decisions change.
- Do not mix unrelated changes in one pull request.
