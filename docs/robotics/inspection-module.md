# Inspection Module

## Overview

The Inspection Module is a comprehensive autonomous inspection system for the AMR-X platform that detects structural defects, overheating, and gas leaks in real-time using multi-sensor data fusion.

## System Components

### Sensors

**RGB Camera**
- High-resolution visual inspection
- Detects cracks, surface damage, and defects
- Uses OpenCV morphological operations for analysis
- Adaptive thresholding for robust edge detection

**Thermal Camera**
- Detects overheating and thermal anomalies
- Identifies hot spots and temperature variations
- Monitors equipment health

**Gas Sensor**
- Detects hazardous gas leaks
- Monitors air quality
- Alerts on dangerous concentration levels
