# AMR-X Documentation

Welcome to the AMR-X project documentation.

AMR-X is a modular autonomous mobile robot (AMR) platform. One base robot
accepts interchangeable functional modules (inspection, secure cargo,
handling, robotic arm) through a shared docking interface.

## Sections

- **System Architecture** — the technical reference covering mechanical,
  electrical, software, and module-interface decisions, maintained by the
  Technical Project Manager / System Architect. Includes the interface
  table tracking every cross-team decision and known conflicts.

More sections (mechanical design, ROS/simulation, navigation, dashboard,
embedded/electrical) will be added here as each team's documentation is
migrated into this site.
